# Constitution

1. Official perps evidence is authoritative. Provenance and missingness are part of the data model.
2. Strict typed contracts separate venue wire data, analytics, presentation and execution.
3. Public reads never expose account credentials. Local control is guarded; live writes are opt-in and single-attempt.
4. Live financial behavior is verified with mocked transport before owner-operated use; ambiguous writes halt. Every execution intent has an audit trail. Feature 002 removes paper from the product UI at the user's request while retaining simulator regression coverage.
5. Reference repositories are inspected read-only. No copied secrets, databases or running bot state.
6. Validate financial calculations, failure paths, API integration and responsive UI. No live financial action is needed for delivery.
